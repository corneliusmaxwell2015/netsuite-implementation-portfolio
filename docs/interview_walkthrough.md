# Interview Walkthrough Script

Use this script to confidently walk through your GitHub portfolio during interviews.

---

## Opening Statement

“I built a NetSuite implementation portfolio that demonstrates real SuiteScript development, functional design, and SOC 2–aligned architecture thinking. It covers credit governance, customer onboarding automation, inventory visibility, and revenue processing.”

---

## Step-by-Step Walkthrough

### 1. Start with the README
Highlight:
- Badges
- Overview
- Structure

### 2. Open the SuiteScripts folder
Explain each category:
- UE scripts → business rules
- RESTlets → integrations
- Suitelets → UI dashboards
- Map/Reduce → batch processing
- Workflow Action → audit logging
- Scheduled → automation
- Portlet → dashboard widgets

### 3. Show the Saved Searches
Explain how they support:
- Inventory visibility
- Credit risk reporting
- Operational insights

### 4. Open the Case Study
Walk through:
- Business problems
- Technical solutions
- Architecture
- SOC 2 alignment
- Business impact

### 5. Show the Architecture Diagram
Explain:
- Data flows
- Script interactions
- Compliance considerations

### 6. Close with Confidence

“This portfolio shows I can take a business problem, design a solution, implement it in SuiteScript, and document it in a way that aligns with enterprise standards like SOC 2.”
